# NoFreezeFrame v1.0.1

For **Hollow Knight 1.5.78.11833 + Modding API 74**.

## What's New

- Choose which freezes to remove using individual settings for numbered presets 0–5, direct timed freezes, the bool overload, and `FreezeMomentGC`.
- All removal settings default to On and are saved between sessions. Turn an individual option Off to preserve that freeze type.
- The master toggle still enables or disables the entire mod. Numbered preset settings take precedence over the direct timed setting when a preset calls the timed method.

Different game events can share a preset. The direct timed option includes player damage freezes and other direct calls to that method. Normal menu pause is preserved; performance stutters and freezes implemented outside the covered methods are not addressed.

## Installation

Download `NoFreezeFrame-1.0.1.zip` and extract the `NoFreezeFrame` folder into `hollow_knight_Data/Managed/Mods/`. Alternatively, place `NoFreezeFrame.dll` in `hollow_knight_Data/Managed/Mods/NoFreezeFrame/`.

Open **Options → Mods → No Freeze Frames** to configure the mod. The master toggle takes effect when leaving the menu.

## Validation

The release was built against the target game's assemblies. The v1.0.1 per-type settings and menu interactions have not yet been verified in gameplay.
