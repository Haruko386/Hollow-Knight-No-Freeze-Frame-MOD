# NoFreezeFrame v1.0.0

适用于 **Hollow Knight 1.5.78.11833 + Modding API 74**。

## 功能

- 拦截全部四个 `GameManager.FreezeMoment` / `FreezeMomentGC` 全局冻结入口，覆盖经这些入口触发的命中、击杀、受伤、特殊停顿和慢动作。
- 在 **选项 → 模组（Mods）→ 消除冻结帧（No Freeze Frames）** 中开关，默认开启；返回菜单后应用，无需重启。
- 开关状态由 Modding API 保存；关闭后恢复原版冻结效果。
- 保留菜单暂停、场景切换、敌人硬直与击退；只依赖 Modding API。

## 安装

推荐下载 `NoFreezeFrame-1.0.0.zip`，将其中的 `NoFreezeFrame` 文件夹解压到游戏的 `hollow_knight_Data/Managed/Mods/`。

也可下载 `NoFreezeFrame.dll`，手动放入 `hollow_knight_Data/Managed/Mods/NoFreezeFrame/`。

## 验证与范围

已使用目标版本游戏程序集编译通过，游戏日志确认模组成功加载、四个钩子成功注册。实战效果及菜单交互尚未完成验证。

本模组处理游戏刻意产生的全局冻结效果，不解决性能掉帧、磁盘加载或一般 GC 卡顿。其他模组绕过上述入口自行实现的停顿，以及开关应用前已启动的冻结协程，不受本次拦截影响。

源码及发布包采用仓库中的 Apache-2.0 许可证。
