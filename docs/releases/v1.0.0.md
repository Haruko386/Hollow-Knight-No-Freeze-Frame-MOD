# NoFreezeFrame v1.0.0

For **Hollow Knight 1.5.78.11833 + Modding API 74**.

## Features

- Blocks all four `GameManager.FreezeMoment` / `FreezeMomentGC` entry points, covering hitstop, kills, player damage, special freezes, and slow motion triggered through these methods.
- Adds a toggle under **Options → Mods → No Freeze Frames**. Enabled by default; changes apply when leaving the menu, without restarting the game.
- Saves the toggle state through Modding API. Disabling the mod restores the original freeze behavior.
- Preserves menu pause, scene transitions, enemy stun, and knockback. Requires only Modding API.

## Installation

Download `NoFreezeFrame-1.0.0.zip` and extract the `NoFreezeFrame` folder into the game's `hollow_knight_Data/Managed/Mods/` directory.

Alternatively, download `NoFreezeFrame.dll` and place it in `hollow_knight_Data/Managed/Mods/NoFreezeFrame/`.

## Validation and Scope

Builds successfully against the target game's assemblies. The game log confirms that the mod loads and all four hooks register successfully. Combat behavior and menu interactions have not yet been fully tested.

The mod removes intentional global freeze effects. It does not address performance drops, disk loading, or general garbage collection stutters. Freezes implemented by other mods outside these entry points, and freeze coroutines already running before the toggle takes effect, are unaffected.
